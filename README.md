# ClinIQ v9 — Clinical Detective

Versão v9 do ClinIQ, focada na experiência **“Shazam da consulta médica”**, com captura por esfera, compreensão clínica em tempo real, Clinical Detective, evidências auditáveis e prévia de dossiê premium.

## Publicação

Este projeto está preparado para publicação no Vercel com Next.js. A experiência principal fica preservada em `public/cliniq-v9.html` e é renderizada na rota raiz por `app/page.tsx`.

## Comandos

```bash
pnpm install
pnpm build
pnpm start
```
